## To run the project locally you must create user secrets file 'secrets.json'
The file looks like this<br>
{<br>
  &nbsp;&nbsp;"OmdbAPI": {<br>
    &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;"ApiKey": "[Your Api Key]"<br>
  &nbsp;&nbsp;}<br>
}<br><br>
Where the api key can be obtained from https://www.omdbapi.com/apikey.aspx
